# Contributing

This repository is a scientific reference publication, not a collaborative
software project. Contributions are limited to specific categories.

---

## What You Can Contribute

### Research questions and clarifications

If you have a question about the V5 methodology, results, or scope conditions,
open an issue using the **Research Question** template.

Appropriate topics:
- Clarification on measurement scope or boundary conditions
- Questions about how a specific result was obtained
- Requests for additional context about a reported finding

Inappropriate topics:
- Requests to reproduce results using undisclosed implementation details
- Requests for proprietary benchmark fixtures, raw data, or internal tooling
- Requests for implementation source code

### Documentation corrections

If you find a factual error in the documentation (not in the white paper itself),
open an issue using the **Documentation Issue** template.

The white paper PDF is the authoritative source. If the documentation in this
repository contradicts the paper, the paper takes precedence.

---

## What We Do Not Accept

- Pull requests modifying the white paper or its reported results
- Fabricated benchmark reproductions claimed as independent verification
- Changes to evidence classification or provenance records
- Modifications that claim research findings not present in V5
- Promotional content, partnerships, or commercial solicitations

---

## Process

1. Open an issue using the appropriate template.
2. The maintainers will respond.
3. If a correction is warranted, it will be applied by an authorized maintainer.

There is no automated merge process for external pull requests against the
research content.
